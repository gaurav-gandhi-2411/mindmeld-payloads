# mindmeld-payloads

Static daily puzzle payloads for [Mindmeld](https://github.com/gaurav-gandhi-2411/mindmeld), served via GitHub Pages.

Layout: `{lang}/{yyyy-mm-dd}.json.gz` + `manifest.json`. Generated by `mindmeld/generator` — do not edit by hand.

Changes land by pull request only. The required `validate-payloads` check
(`ci/validate_payloads.py`) fails if a published date file is modified or deleted, and
decodes every added or modified payload to check its schema, rank permutation, answer, and
the vendored blocklist (`ci/blocklist.txt`, regenerated from the generator). Run it locally
with `python ci/validate_payloads.py origin/main`.
